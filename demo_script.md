# 90-second demonstration

0–15 seconds: State the task: "I tested cross-cohort transfer of a lung tumor tissue
classifier using public TCGA and GEO expression data."

15–35 seconds: Show the cohort table and explain that tumor/normal samples from the
same person remain in the same cross-validation fold. Point out the locked external set.

35–55 seconds: Show the external confusion matrix: 80/87 tumors detected, 77/77 normals
correctly classified in the reported run. Show uncertainty and the QC-only baseline.
Use the exact values from the completed evidence review.

55–75 seconds: Show the 25-gene signature, contrasting replicated expression associations
with unstable model selection. Explain why the rank transformation still needs thousands
of genes. Show an actual enriched pathway only after reviewing the saved table.

75–90 seconds: Show reproduction instructions and tests. End with the next experiment:
a prespecified additional cohort/negative-control evaluation. State that this does not
validate a blood screening test. Record your own explanation of these decisions.
